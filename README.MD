## 📌 Project Overview
This repository contains the code for **Assignment 2** on modern layout techniques in Front-End Development. The project demonstrates the usage of **CSS Flexbox** and **CSS Grid** to build flexible, responsive, and well-structured web interfaces.

---

## 🛠 Features & Tasks

- **Task 0. Navigation Bar (Flexbox):**
  - Header with logo aligned on the left and navigation links on the right.
  - Spacing and vertical alignment using Flexbox (`justify-content`, `align-items`).

- **Task 1. Card Row (Flexbox):**
  - Card container with 3 items of equal height (`align-items: stretch`).
  - Interactive hover effects (card elevation and shadow).

- **Task 2. Page Layout (Grid Areas):**
  - Full-page layout structured with `grid-template-areas` (Header, Sidebar, Main Content, Footer).

- **Task 3. Image Gallery (CSS Grid):**
  - Responsive image grid with equal columns and custom gaps.
  - Smooth hover overlay displaying image captions.

- **Task 4. Portfolio Page (Combined Layout):**
  - Combining Flexbox for internal card mechanics with CSS Grid for overall page architecture.
